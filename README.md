## The line

> I asked my grandfather the secret to his 60-year marriage. He said, 'I never corrected your grandmother in public — I saved it all for the eulogy.'

## How it works

`main.ts` (Node 22+) writes that single line — 147 characters, no title, no setup, no explanation — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic: no randomness, no network, no clock. Two runs produce byte-identical output.

```sh
node main.ts
```
